# Court OCR Scanner

Flutter Android project for scanning court documents, reviewing OCR results, and exporting an Excel register.

## Build
GitHub Actions automatically builds the release APK on pushes to `main` or via **Actions → Build Court OCR Scanner APK → Run workflow**. This source archive does not contain a prebuilt APK: the APK is generated by the workflow. Download `Court-OCR-Scanner-APK` from the successful run's Artifacts section.

### Build from this ZIP using GitHub (phone-friendly)
1. Extract this ZIP and upload its contents to the root of a GitHub repository on the `main` branch (keep the `.github/workflows/build-apk.yml` path).
2. Open the repository's **Actions** tab and select **Build Court OCR Scanner APK**.
3. Tap **Run workflow** and run it on `main`.
4. Wait for all required build/test steps to finish successfully. Open the run and download **Court-OCR-Scanner-APK** under **Artifacts**.
5. Extract the artifact ZIP; it contains `app-release.apk`. Install it on your Android phone and allow installation from that source if Android asks.

If the workflow fails, open the failed step and use its first error message; do not install an artifact from a failed run.

## Features in this starter
- On-device Latin-script OCR from camera/gallery.
- Editable preview for mapped columns A, B, C, D, E, F, G, H, I, J, K, P, Q, R, T, W, AE, AF, AM.
- Load an existing `.xlsx` workbook and append to the first/`Visible Data` sheet, leaving other columns in place.
- W assignee options saved in app settings and can be added, edited, or removed.
- AE, AF, AM dropdown options.
- Excel export via Android share sheet.
- Date/month formatting helpers.

## Important limitations to verify before official use
- OCR field extraction uses heuristics; it is not a certified legal-document parser. Always review every field before saving.
- The workbook must have a compatible first worksheet; protect/backup the original register before testing.
- Registration numbering and daily serial behavior should be validated against the real workbook layout. This starter counts existing matching court names and scan dates in the loaded workbook.
- The app exports an Excel file. Direct Google Sheets synchronization is not configured in this source.
- Test on a real Android device; GitHub Actions build success does not prove runtime correctness.

## Build the Android APK on GitHub

1. Upload the complete project contents to the root of a GitHub repository.
2. Ensure `.github/workflows/build-apk.yml` is present on the `main` branch.
3. Open **Actions** → **Build Court OCR Scanner APK** → **Run workflow**.
4. After the run succeeds, open the run and download the `Court-OCR-Scanner-APK` artifact.
5. Extract the downloaded artifact ZIP to get `Court-OCR-Scanner.apk`.

The workflow generates Android platform files when they are absent, installs packages,
runs `flutter analyze` and `flutter test`, builds a release APK, checks that the APK exists,
and uploads it as an artifact.

## Current scope

The app performs on-device Latin-script OCR, provides an editable review form, and exports
an Excel workbook. It does not currently sync directly to Google Sheets. OCR extraction is
heuristic, so verify every field against the original court document before using the exported
register for official work.
